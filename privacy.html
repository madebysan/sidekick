Sidekick Privacy Policy

Last updated: October 11, 2026

Overview

Sidekick is a Chromium extension for Brave, Chrome, and similar browsers that lets you chat with AI about any webpage. It is designed to keep your data local. There is no server, no account, no analytics, and no tracking. This policy explains exactly what data is handled and where it goes.

Auto-submit command on start is optional and off by default. If enabled, opening an empty chat sends your selected command and active page or transcript context to your selected AI provider, just like submitting that command manually. You can change the command or turn this off in Settings → Commands.

Data stored on your device

The following data is stored locally in your browser using chrome.storage.local and is never transmitted to any server:

  • Settings and preferences — theme, chat style, font, model selection, max context length, web search, custom system prompt, explicit memory preferences
  • API keys and local endpoints — your Anthropic, OpenAI, Fal.ai, Gemini, and/or DeepSeek API key, optional ElevenLabs API key, optional local LM Studio endpoint, and optional Kokoro endpoint are stored locally and only used when making requests
  • Custom slash commands — command names and prompt text you create
  • UI state — chat window size
  • Conversation data — temporarily stored while a tab is open, used for optional auto-saving when the tab closes

When Auto-Save Conversations is enabled, saved conversation logs and audio files are written to your local Downloads folder (Downloads/Temp/sidekick-logs/) and are not transmitted anywhere.

Data sent to your cloud AI provider (Anthropic, OpenAI, Fal.ai, Gemini, or DeepSeek)

You choose the provider in Settings. When you send a message with Anthropic, OpenAI, Fal.ai, Gemini, or DeepSeek selected, the following is transmitted directly from your browser to that provider's API (api.anthropic.com for Claude, api.openai.com for OpenAI, fal.run for Fal.ai, generativelanguage.googleapis.com for Gemini, api.deepseek.com for DeepSeek):

  • Your message text and conversation history for the current tab
  • Memory preferences you explicitly saved
  • Page content or YouTube transcript text, if context is active
  • Images you attach via drag-and-drop or screenshot, sent as base64-encoded data. Fal.ai image sends only go out when the selected OpenRouter model supports vision. DeepSeek is text-only in Sidekick, so those cloud image sends require Claude, a compatible OpenAI model, or a vision-capable Fal model.
  • The API key for the selected provider (for authentication)
  • The selected model name
  • If Web search is on, live search queries through Fal.ai/OpenRouter. Page-grounded commands such as /tldr and /contrarian do not search. /research does search when the toggle is on.

Sidekick also calls configured cloud providers' model-list endpoints to refresh available model names. Fal.ai model choices are refreshed from OpenRouter's public model catalog at openrouter.ai because fal's openrouter/router endpoint accepts OpenRouter model IDs. Local model choices are refreshed from your configured LM Studio endpoint at /v1/models. Provider model lists are cached in chrome.storage.local. API calls go directly from your browser to the provider. No proxy server or intermediary is involved. The provider's own privacy policy governs how they handle API requests: Anthropic, OpenAI, Fal.ai, Google, and DeepSeek.

Data sent to your local model server

This only applies if you select Local (LM Studio) in Settings. When you send a message, Sidekick sends your message text, conversation history, active page context, memory preferences, selected model name, and custom system prompt to the configured localhost endpoint. The default endpoint is http://localhost:1234/v1/chat/completions.

Local mode does not use an API key. Sidekick restricts local model endpoints to localhost or 127.0.0.1. These requests stay on your computer unless your local model server is configured to forward data elsewhere. Screenshot and drag-and-drop images are sent to the local endpoint only when the selected local model is Gemma 4.

Data sent to ElevenLabs (api.elevenlabs.io)

This only applies if you enable ElevenLabs text-to-speech in Settings. When you click "Speak" on an assistant message or "Listen" for the current page:

  • The plain text of that message, page article, or YouTube transcript is sent to the ElevenLabs API
  • Your ElevenLabs API key is sent for authentication

If you do not configure an ElevenLabs API key or use the browser or Kokoro voice engine, no data is sent to ElevenLabs. ElevenLabs' own privacy policy governs how they handle API requests.

Data sent to your local speech server

This only applies if you select Kokoro text-to-speech in Settings. When you click "Speak" on an assistant message or "Listen" for the current page, Sidekick sends the plain text of that message, page article, or YouTube transcript and selected voice to your configured local speech server.

Kokoro defaults to http://localhost:8789 and uses a /config and /download protocol. Sidekick does not include a Kokoro server; you run your own.

Sidekick restricts local speech endpoints to localhost or 127.0.0.1. These requests stay on your computer unless your local speech server is configured to forward data elsewhere.

Data sent to Google (fonts.googleapis.com)

The default font is your system font, which makes no request to Google. If you select DM Sans, IBM Plex Sans, or Source Sans 3 in Settings, the font is loaded from Google Fonts when the chat opens. The Settings page also loads these three fonts from Google Fonts to show previews.

Data NOT collected

  • No analytics, telemetry, or usage tracking of any kind
  • No browsing history, page URLs, or tab information is stored or transmitted beyond the active conversation context
  • No data is sent to any server operated by the extension developer
  • No cookies are set or read
  • No personal information is collected, sold, or shared with third parties
  • Settings exports include explicit memory preferences and explicitly exclude API keys

Permissions used

  • storage — Saves your settings and preferences locally in the browser
  • activeTab — Reads the current page content when you click the extension icon, and captures screenshots when you click the camera button
  • scripting — Injects the chat interface into the active tab when you click the extension icon
  • downloads — Saves conversation logs and audio files to your Downloads folder when Auto-Save Conversations is enabled

Data retention

Conversation data is held in memory while the tab is open. If Auto-Save Conversations is enabled, it is written to your local Downloads folder when the tab closes. It is then removed from browser storage. Settings persist until you uninstall the extension or clear extension data.

You can delete saved conversation files from your Downloads folder at any time. Uninstalling the extension removes all stored settings and API keys.

Children's privacy

Sidekick is not directed at children under 13 and does not knowingly collect any personal information from children.

Changes to this policy

If this policy is updated, the "Last updated" date at the top will change. Continued use of the extension after changes constitutes acceptance of the updated policy.
